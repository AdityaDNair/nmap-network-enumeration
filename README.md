# Nmap Network Scanning and Enumeration Lab

## Overview
This project demonstrates the use of Nmap for network discovery, service enumeration, operating system detection, and vulnerability scanning.

## Tools Used
- Nmap
- Windows Command Prompt

## Target
- scanme.nmap.org

## Scans Performed

### 1. Basic Scan
Identified open ports on the target system.

### 2. Service Version Detection
Enumerated versions of services running on open ports.

### 3. OS Detection
Performed operating system fingerprinting.

### 4. Aggressive Scan
Executed advanced scanning techniques including traceroute and NSE scripts.

### 5. Full Port Scan
Scanned all TCP ports to identify additional exposed services.

### 6. Vulnerability Scan
Executed Nmap NSE vulnerability scripts to identify potential security issues.
